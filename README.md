# ☁️ Linux & Cloud Labs

Repositório criado para documentar meus estudos práticos em Linux, Redes, Git, AWS e Cloud Computing.

A proposta é consolidar conhecimentos por meio de laboratórios práticos, registrando configurações realizadas, dificuldades encontradas, soluções aplicadas e principais aprendizados.

## 🧪 Laboratórios

### 01 — Preparação de ambiente Linux para Cloud
Configuração inicial do ambiente de estudos e preparação para práticas de infraestrutura e computação em nuvem.

📂 [Acessar o Laboratório 01](https://github.com/JessCereja/linux-cloud-labs/tree/main/01-linux-cloud-setup)

### 02 — Introduction to Amazon EC2
Criação e gerenciamento de uma instância EC2, configuração de servidor web Apache, regras de segurança para acesso HTTP, monitoramento e redimensionamento de recursos.

📂 [Acessar o Laboratório 02 — Amazon EC2](https://github.com/JessCereja/linux-cloud-labs/tree/main/02-introduction-to-amazon-ec2)

Desenvolver e documentar habilidades práticas em infraestrutura, computação em nuvem e troubleshooting, fortalecendo meu portfólio para oportunidades em Suporte Técnico e Cloud Support.

Este repositório está em constante evolução, acompanhando meu aprendizado e a realização de novos laboratórios.
